# Worker productivity and quality of life among adults with T2DM

This is a respository for a project at UCSD's DIMM clinic. 

Proposed title of the project: "**Impact of SGLT2 and GLP1RA Use on Productivity Loss and Veterans Rand-12 Health Survey (VR-12) Physical and Mental Health in U.S. Adults with Type 2 Diabetes using pooled data from the Medical Expenditure Panel Survey (2018 to 2022)**"

We will use [MEPS data](https://meps.ahrq.gov/mepsweb/) to perform this analysis. 

A collection of the literature that will be helpful for this project are located in the [Literature folder](https://github.com/mbounthavong/Worker-productivity-and-quality-of-life-among-T2DM/tree/main/Literature). 

The HCUP crosswalk contains mapping between the ICD10 code and CCSR code. The 2025 HCUP crosswalk file is located in the [HCUP Crosswalk ICD10-CCSR folder](https://github.com/mbounthavong/Worker-productivity-and-quality-of-life-among-T2DM/tree/main/HCUP%20Crosswalk%20ICD10-CCSR).
